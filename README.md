# News

A website that gets and summarizes latest news for you with AI. We also have an API that doesn't have documentation yet (thumbsup emoji)

## Requirements

- Node.js 20 or higher
- Hack Club AI API key
- Groq API key


## Running

```bash
npm install
npm run dev
```

## Deploy to Vercel

This is made to be hosted on Vercel.

- `/` news page.
- `/api/news` latest news json.
- `/api/health` is the thing up or not?
- `POST /api/refresh` manual refresh. (i will remove this soon)
