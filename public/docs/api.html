API References

Here is how to get latest news, uptime and more!

Latest news

GET/api/news

Contains the latest news articles, latest refresh time, next refresh and errors in a JSON.

curl https://news.superman2775.eu/api/news

Each article includes an id, subject, title, summary, body, sources, and generatedAt.

Health

GET/api/health

Status about the API. Contains: ok, refreshedAt, nextRefreshAt, articleCount, and refreshing.

Manual refresh

POST/api/refresh

Temporary, removed later.

Scheduled refresh

GET/api/cron/refresh

Says when it will refresh next when hosted on Vercel.
