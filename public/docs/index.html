Welcome to the news API docs! Here, you can find a way to set up this API yourself, and how to use the API.

How it works

  1. Search The system searches for a bunch of articles about different topics.
  2. Summarize Our very strong AI powered summarisation systems start to read everything and write the perfect articles.
  3. Publish After the AI analyzation, all the articles are published to our home page and the API.
  4. Repeat The news gets refreshed daily so you get a fresh look on the facts each day.
